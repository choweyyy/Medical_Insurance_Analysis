# 🏥 Medical Insurance Dashboard

An interactive Medical Insurance Dashboard built with **Google Looker Studio** to analyze insurance members, medical costs, claims, and healthcare risk. The dashboard provides a comprehensive overview of key performance indicators and claim analysis through interactive filters and visualizations.

---

## 📌 Project Overview

This dashboard was created to help stakeholders monitor medical insurance performance and identify trends in healthcare costs, claims, and member risk.

The report consists of two interactive pages:

- **Executive Overview**
- **Claim Analysis**

---

## 🛠️ Tools Used

- Google Looker Studio
- Google Sheets
- SQL (for data preparation)
- GitHub

## ✨ Features

### Executive Overview

- Total Members
- Total Medical Cost
- Total Claims Paid
- Average Medical Cost
- Average Claims per Member
- High Risk Members
- Average Annual Medical Cost by Age
- Average Medical Cost by Region
- Gender Distribution
- Members by Plan Type
- Average Medical Cost by Smoker Status
- High Risk Member Percentage

### Claim Analysis

- Total Claims
- Average Claim Amount
- Total Claims Paid
- Average Claims per Member
- Total Procedures
- Hospitalization Count
- Claim Count by Age
- Claim Paid by Plan Type
- Average Claim Amount by Region
- Claim Count vs Medical Cost
- Top Procedures by Count

---

## 🎛️ Interactive Filters

Users can filter the dashboard by:

- High Risk Status
- Network Tier
- Gender
- Region
- Age

All KPIs and visualizations update dynamically based on selected filters.
